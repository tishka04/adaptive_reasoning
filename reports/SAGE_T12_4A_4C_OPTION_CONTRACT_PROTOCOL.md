# SAGE.T12.4a.4c — Sparse option applicability and effect contracts

## Parent evidence and hypothesis

T12.4a.4b passed its diagnostic gate with
`INITIATION_AND_DYNAMICS_SHIFT`: all 16 prefixes were exact, the option
progressed in 4/4 level-0 trials and 0/4 level-1 trials, and the first
structured transition already differed. T12.4a.4c tests whether that result can
be represented honestly inside the common causal posterior.

The hypothesis is not that the five-action sequence transfers. It is that SAGE
can compile it as a **guarded local option**: available only under a sparse
initiation predicate and monitored by one typed effect contract per action.

## Frozen induction vocabulary

The new iteration reads only the sealed T12.4a.4b structured descriptors. It
uses six action-relevant aggregate features:

- role counts: `clickable`, `movable`;
- relation counts: `adjacent`, `aligned`, `contact`, `near`.

Pixels, exact hashes, game or level identity, absolute coordinates, grounded
entity identifiers and raw fact-token multisets are forbidden. The legacy
option artifact remains checksum-bound, but its exact initiation hash is never
consulted by the contracted provider.

Each initiation predicate is retained as a separate one-atom posterior
particle. A predicate is admissible only when it has the same value in both
independent successful lineages and a different value in every failed anchor.
The protocol requires four to six rival predicates rather than selecting one
post hoc.

For each of the five option steps, an effect atom is admissible only when its
non-zero signed delta is identical across both successful lineages and differs
in every failed trace. At most three atoms are retained per step. This yields a
small effect monitor rather than a copy of the full scene graph.

## Common-posterior compilation

The four complete parent programs from T12.4a.3 are crossed with at most six
initiation hypotheses, for a hard maximum of 24 complete particles. Each child
contains:

- an observed typed context variable;
- an explicit Boolean applicability mechanism;
- a guarded finite-state option mechanism;
- the five step-effect contracts in the mechanism metadata;
- the original dynamics and goal of its parent program.

The MDL cost added by the contract is identical across parent theories, so the
aggregate posterior mass of each of the four parent programs must be preserved
to numerical tolerance.

## Offline controls and gate

T12.4a.4c performs zero ARC SDK calls. The shadow gate requires:

- all successful anchors to have applicable posterior mass at least 0.8;
- all failed anchors to have zero applicable mass;
- every success effect trace accepted and every failed step rejected;
- positive automata to complete and failed-context automata never to advance;
- deleted and reversed action controls to fail;
- shuffled effect order to reject success;
- guard and effect ablations to expose the failed context;
- both role and relation guard families to remain represented;
- all 24 or fewer programs to compile in the canonical executor;
- parent posterior masses to remain unchanged;
- no forbidden input, SDK call or storage violation.

A pass means only that SAGE can represent the discovered option without making
the false level-1 transfer prediction. It does not demonstrate new progress.
It may authorize a separate T12.4a.4d target-local re-grounding/search freeze.
Option control, neural training, source validation, holdout and production
authority remain closed. A failure stops the chain and is reported as a
negative scientific result.
