# SAGE.T10.3.12b — Factorial invariant identification

## Scientific scope

T10.3.12b is a corrective, zero-physical-action experiment. T10.3.12 showed
that its factorized source arm and source-free grammar both solved all eight
core resets with the same action counts and the same grounded trajectories.
The new question is narrower: which parts of the two successful mechanisms
remain necessary under preregistered causal interventions?

The experiment can identify transportable **factor candidates**. It cannot
claim that they generalize to an unseen game. A positive result authorizes only
preregistration of a later cross-game falsification experiment. It does not
open sequence games, source validation, holdouts, production authority, or
automatic retuning.

## Parent constraint

The T10.3.12 manifest, registry, offline report, active report, adjudication,
terminal report, and complete journal are checksummed at freeze. The parent
must remain the clean `GENERIC_REDISCOVERY_ONLY` result with 336 authorized and
336 sealed actions, no inflight intent, no replay, and closed authority.

The audit independently verifies that source and generic arms have one exact
grounded trajectory per core game and that these trajectory sets match. It
also records the legacy fallback contamination confined to negative-control
arms. Parent actions are diagnostic only: they are not used for training,
support, fitting, or factor compilation.

## Frozen factorization

Each mechanism is represented by four factors:

1. `operator`: use the parameterized application schema;
2. `role_binding`: use the actual T10.3.12 observable proxy — minimum boundary
   distance or the salient goal end — as a prior, verify it with a bounded
   causal probe, and rebind when the probe contradicts the proxy;
3. `transition`: remain on the same role until progress or follow the
   topological successor toward the goal end;
4. `termination`: stop on progress or structural ambiguity.

Persisted factor programs contain no game identity, seed, coordinates, raw
grid, entity identifier, action argument, argument checksum, or grounded path.
All parent programs enter with zero local support, and no T10.3.12b program can
be promoted.

## Experimental arms

- `factorized_source`: all four source-projected factors, with observable role
  proxies used as verified priors rather than oracle productive labels;
- `generic_source_free`: the same operator and transition grammar, but it must
  pay explicit virtual probes before binding a causal role or path direction;
- `operator_ablation`: only the operator factor is replaced;
- `role_binding_ablation`: only the causal role is replaced by candidate order;
- `transition_ablation`: only repeat accumulation or path succession is
  destroyed;
- `termination_ablation`: only the progress stop is removed.

There is no fallback between arms. An arm either acts according to its frozen
factorization or abstains.

## Counterfactual matrix

The runtime materializes 128 compact symbolic states:

- two contexts: repeat and path;
- eight D4 transformations;
- canonical and reverse candidate order;
- four challenges: short positive, long positive, ambiguous role, and
  structural-causal relation decoupling.

The first four transformations form the identification split; the remaining
four form the challenge split. Compilation occurs before intervention scores
are produced. The matrix contains 96 execute-and-stop cases and 32 ambiguity
cases, preventing a universal target label.

In the decoupling control, the observable boundary or salient-end proxy remains
fixed while the productive target or causal goal end is moved. This is the
principal falsification of a game-specific proxy: the source arm must detect
the contradiction and rebind, not blindly follow the proxy. The decoupled
state shares its observable state hash with the corresponding long positive;
only its transition law changes.

These are interactive symbolic interventions, not ARC actions. Generic probes
are charged as virtual actions so that source information has to change either
the first decision or the intervention cost. The report keeps this accounting
separate from physical environment accounting.

## Required gates

All gates are conjunctive:

- 12/12 zero-action preflight checks;
- 128/128 correct factorized-source trials;
- 128/128 correct generic trials;
- 32/32 correct source abstentions on ambiguity;
- 32/32 correct source trials when the structural proxy is decoupled from the
  causal role;
- at least 48 distinct compact state hashes in each context;
- one stable program hash per arm/context;
- source/generic first-decision divergence on at least 96 executable variants;
- source median virtual actions at most 80% of generic in each context;
- every factor ablation loses at least eight correct trials per context and at
  least four challenge-split trials per context;
- at most 32,768 virtual actions, 600 seconds, 5 MiB of compact artifacts, and
  exactly zero physical actions.

`GENERIC_PRIOR_ONLY`, any factor-specific miss, or insufficient state diversity
is a valid negative result. It must be sealed without live repair or retuning.
The adjudication grades evidence separately: operator and transition may use
the existing active schema/relation contrasts, whereas termination remains
`counterfactual_only_no_parent_active_ablation` until an independent live stop
control exists. A role proxy rejected by decoupling is reported explicitly and
is not silently replaced during the frozen run.
If the source proxy fails while the source-free probing arm remains exact, the
report records `interventional_rebinding` as an alternative candidate
mechanism. Its evidence is counterfactual: the parent active run established
only an aligned-state behavioral tie, not that those probes were physically
executed. This is a diagnosis, not an in-run substitution or promotion.
